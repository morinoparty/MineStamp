## MineStampとは？

Minecraftで、このプラグインを使用すると、プレイヤーがコマンドを使用した際に頭上に絵文字を表示することができます。
また、サーバー管理者がアップロードした画像をスタンプとして使用することも可能です。

## 絵文字について

絵文字にはMicrosoft Fluent Emojiを使用しています。<br />
この絵文字は[fluentui-emojiリポジトリ](https://github.com/microsoft/fluentui-emoji)を元にした[fluent-emoji-webfont](https://github.com/tetunori/fluent-emoji-webfont)から取得し、MIT Licenseの下で使用しています。

以下は、プラグイン内蔵のレンダラーでフォントから抽出したカラー絵文字の例です（`:thinking-face:` `:cucumber:` `:angry-face:` `:sleeping-face:`）。
