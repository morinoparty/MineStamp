## 🧭 概要

MineStamp のゲーム内テストは、[fukurou](https://github.com/morinoparty/fukurou) を使って実行します。fukurou は、実際の Paper サーバーと、プレイヤーごとのバニラ Minecraft クライアントを起動し、JSON のシナリオどおりに操作してスクリーンショットを保存します。
GitHub Actions ではプルリクエストごとに実行され、全バージョンの結果をまとめたビューアへのリンクが PR にコメントされます。

## 📝 シナリオ

シナリオは `game-test/scenarios/` に置きます。`stamp-thinking-face.json` では、次の操作を行います。

1. Alice（OP）と Bob が参加します。
2. Alice は石の柱の上から F5 を2回押して正面から見た視点にし、`/st :thinking-face:` を実行します。
3. Alice の視点と、向かいに立つ Bob の視点でスクリーンショットを撮ります。
4. スタンプのクールダウン（表示時間 3 秒 + 待機時間 5 秒）が明けてから、Alice が `/st :sleeping-face:` を実行し、もう一度 2 人の視点でスクリーンショットを撮ります。

シナリオの書き方は、[fukurou の README](https://github.com/morinoparty/fukurou#readme) を参照してください。手元でシナリオを検証するには、次のコマンドを実行します。

```sh
uvx --from git+https://github.com/morinoparty/fukurou fukurou validate --scenario-file game-test/scenarios/stamp-thinking-face.json
```

## ⚙️ ワークフロー

`.github/workflows/game_test.yml` は、次のジョブで構成されています。

| ジョブ | 内容 |
| --- | --- |
| `versions` | `morinoparty/fukurou/versions` で、テストするバージョンの一覧を決めます（既定は `1.21.6-`）。 |
| `build` | プラグインを1回だけビルドします。 |
| `test` | バージョンごとに `morinoparty/fukurou` でシナリオを実行します。ProtocolLib も一緒に導入します。 |
| `deploy` | `morinoparty/fukurou/ui` で全バージョンの結果をまとめたビューアを作り、S3 にアップロードします。 |
| `preview` | ビューアへのリンクを PR にコメントします。 |

MineStamp は Java 25 のバイトコードでビルドされており、Paper 1.21.4 以前では読み込めない（`Unsupported class file major version 69`）ため、既定の範囲は 1.21.6 以降にしています。`Game test` ワークフローを手動で実行するときは、バージョンの範囲とシナリオを選べます。

テストを実行すると Minecraft のサーバーとクライアントを起動するため、[Minecraft EULA](https://www.minecraft.net/eula) に同意したことになります。
