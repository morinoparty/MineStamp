## 🧭 Overview

MineStamp's in-game test runs on [fukurou](https://github.com/morinoparty/fukurou). fukurou starts a real Paper server and a vanilla Minecraft client for each player, drives them from a JSON scenario, and saves screenshots.
The server starts only once per version, and every test in that session runs against the same running server. On GitHub Actions it runs for every pull request, and a link to a viewer with the results for all versions is posted on the pull request.

## 📝 Suite and scenarios

MineStamp's in-game test is made of one suite file, `game-test/fukurou.yml`, and several tests under `game-test/scenarios/`. The suite holds what every test shares (players, reset settings, fixtures), and each scenario file is one test. The harness resets the world and the clients between tests.

`fukurou.yml` defines two fixtures:

- `arena` — builds the two stone pillars Alice and Bob face each other from, and teleports them onto their pillar.
- `front-view` — switches Alice's view to the front view by pressing F5 twice. fukurou switches her back to first person before the next test.

There are two tests:

1. `stamp-thinking-face` — Alice runs `/st :thinking-face:`.
2. `stamp-sleeping-face` — Alice runs `/st :sleeping-face:`.

Both tests wait 1.5 seconds after the server log confirms the command, then take both players' screenshots at the same moment with `"on": ["Alice", "Bob"]`. The stamp stays on screen for 3 seconds, so it is still visible 1.5 seconds in. MineStamp's stamp cooldown is 3 seconds of display plus a 5-second `waitSecond`, 8 seconds total. The 1.5-second wait before the previous test's screenshot, the post-reset wait (`settle: 5` seconds) and the fixture's 2-second wait together add up to 8.5 seconds or more, which clears the cooldown before this test's stamp is sent.

See the [fukurou README](https://github.com/morinoparty/fukurou#readme) for the suite and scenario format. To validate the whole suite locally, run:

```sh
uvx --from git+https://github.com/morinoparty/fukurou@v2 fukurou validate --suite game-test/fukurou.yml
```

## ⚙️ Workflow

`.github/workflows/game_test.yml` has these jobs:

| Job | What it does |
| --- | --- |
| `versions` | Resolves the versions to test with `morinoparty/fukurou/versions` (`1.21.6-` by default). |
| `build` | Builds the plugin once. |
| `test` | Runs the whole suite on each version with `morinoparty/fukurou` in a single server session, together with ProtocolLib. |
| `deploy` | Builds a viewer with the results for all versions with `morinoparty/fukurou/ui` and uploads it to S3. |
| `preview` | Posts the test summary (e.g. "14 passed of 14 test runs") and the viewer link on the pull request. |

MineStamp is compiled to Java 25 bytecode, and Paper 1.21.4 and earlier cannot load it (`Unsupported class file major version 69`), so the default range starts at 1.21.6. When you start the `Game test` workflow manually, you can pick a version range and which test ids / tags to run.

Running the test starts the Minecraft server and clients, and accepts the [Minecraft EULA](https://www.minecraft.net/eula).
