## 🧭 Overview

MineStamp's in-game test runs on [fukurou](https://github.com/morinoparty/fukurou). fukurou starts a real Paper server and a vanilla Minecraft client for each player, drives them from a JSON scenario, and saves screenshots.
On GitHub Actions it runs for every pull request, and a link to a viewer with the results for all versions is posted on the pull request.

## 📝 Scenarios

Scenarios live in `game-test/scenarios/`. `stamp-thinking-face.json` does the following:

1. Alice (an operator) and Bob join.
2. Standing on a stone pillar, Alice presses F5 twice to switch to the front view and runs `/st :thinking-face:`.
3. Screenshots are taken from Alice's view and from Bob's, who stands across from her.
4. After the stamp cooldown (3 seconds on screen plus a 5-second wait), Alice runs `/st :sleeping-face:`, and both views are captured again.

See the [fukurou README](https://github.com/morinoparty/fukurou#readme) for the scenario format. To validate a scenario locally, run:

```sh
uvx --from git+https://github.com/morinoparty/fukurou fukurou validate --scenario-file game-test/scenarios/stamp-thinking-face.json
```

## ⚙️ Workflow

`.github/workflows/game_test.yml` has these jobs:

| Job | What it does |
| --- | --- |
| `versions` | Resolves the versions to test with `morinoparty/fukurou/versions` (`1.21.6-` by default). |
| `build` | Builds the plugin once. |
| `test` | Runs the scenario on each version with `morinoparty/fukurou`, together with ProtocolLib. |
| `deploy` | Builds a viewer with the results for all versions with `morinoparty/fukurou/ui` and uploads it to S3. |
| `preview` | Posts the viewer link on the pull request. |

MineStamp is compiled to Java 25 bytecode, and Paper 1.21.4 and earlier cannot load it (`Unsupported class file major version 69`), so the default range starts at 1.21.6. When you start the `Game test` workflow manually, you can pick a version range and a scenario.

Running the test starts the Minecraft server and clients, and accepts the [Minecraft EULA](https://www.minecraft.net/eula).
