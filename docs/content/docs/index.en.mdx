## What is MineStamp?

In Minecraft, this plugin allows players to display an emoticon over their heads when they use commands.
It can also use images uploaded by the server administrator as stamps.

## About emojis

For emojis, we use Microsoft Fluent Emoji.<br />
For this emoji, we have pulled it from [fluent-emoji-webfont](https://github.com/tetunori/fluent-emoji-webfont), which is built from the [fluentui-emoji repository](https://github.com/microsoft/fluentui-emoji), and use it under the MIT License.

Below are examples of color emojis extracted from the font by the plugin's built-in renderer (`:thinking-face:` `:cucumber:` `:angry-face:` `:sleeping-face:`).
