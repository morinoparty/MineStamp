## このアプリケーションの概要
「MineStamp」という、Minecraftサーバー上でスタンプ(絵文字)を利用できるようにするプラグインです。
プレイヤーはチケットなどを通じてスタンプを入手し、チャット等でスタンプを送ることができます。
スタンプ画像やプレイヤーデータはローカルまたはS3互換ストレージに保存され、MineAuthと連携することもできます。

## 主な技術スタック
- Kotlin (言語)
- Koin (依存性注入)
- PaperMC (MinecraftプラグインAPI)
- Cloud (コマンドフレームワーク)
- MCCoroutine (コルーチン)
- AWS SDK for Java (S3互換ストレージ)
